04. Prompts

A collection of go-to prompts I use as a developer — copy them and adapt them to your workflow.

Explain code

Explain the following code step by step, including its purpose, inputs/outputs, edge cases, and any potential pitfalls. Then suggest one improvement.

<paste code>

Debug an error

Here is an error message and the relevant code. Identify the root cause, explain why it happens, and give the minimal fix plus a test that reproduces it.

Error: <error>
Code: <code>

Write tests

Write unit tests for the following function using Jest. Cover the happy path, edge cases, and error handling. Use descriptive test names and avoid testing implementation details.

<paste function>

Refactor

Refactor this code for readability and maintainability without changing behavior. Explain each change and note any trade-offs.

<paste code>

Code review

Review this pull request diff. Flag bugs, security issues, performance problems, and missing tests. Rank findings by severity and suggest concrete fixes.

<paste diff>

Learn a concept

Teach me <concept> as a beginner. Start with a simple analogy, then a minimal example, then a common misconception, and finish with a short practice exercise.

Optimize SQL

Here is a slow SQL query plus its EXPLAIN output. Diagnose why it is slow and rewrite it for performance. Explain what indexes would help.

Query: <query>
Plan: <explain output>

Write docs

Write clear documentation for this function: a one-line summary, parameters with types, return value, side effects, and a usage example.

<paste function>

Plan a feature

I want to build <feature> in <tech stack>. Give me a step-by-step implementation plan: data model, API endpoints, UI components, edge cases, and a definition of done.
